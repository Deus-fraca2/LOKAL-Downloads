## 🧑‍🏫 Setting Up a Classroom Session

A simple routine helps you start a session without stress.

1. Connect the teaching computer to the classroom Wi-Fi or LAN network.
2. Make sure student devices are connected to the same network.
3. Open PowerPoint and prepare or load your lesson slides.
4. Start LOKAL so it can work alongside your presentation.
5. Begin the activity, such as a live quiz or a response prompt.
6. Watch student responses arrive during the lesson.
7. Use stars and leaderboards to recognize participation.
8. Review reports after the activity to understand student engagement.

If students cannot connect, confirm that everyone is on the same local network. A guest Wi-Fi network that isolates devices from each other can prevent connections, so use a network that allows devices to communicate within the classroom.
